# Emmanuel Arihilam — Portfolio

A multi-page personal portfolio built with HTML, CSS and vanilla JavaScript. Intended for free hosting with GitHub Pages.

## Pages
- `index.html` — professional summary and featured projects
- `experience.html` — work history
- `projects.html` — project descriptions and links
- `education.html` — education and credentials
- `contact.html` — professional profiles

## Featured database projects

The Projects page now features two database design assignments with animated, CSS/SVG schema illustrations:

- **Shipping Logistics Database** — Customer, Shipment, and AirwayBill entities; primary/foreign keys; one-to-many and one-to-one relationships. Repository: https://github.com/Pinch1e/SQL
- **E-commerce Database Design** — nine entities spanning customers, orders, products, categories, addresses, carts, and inventory; includes junction entities for order items and cart items. Repository: https://github.com/Pinch1e/E-commerce-database-design

The visuals are explanatory illustrations of the schemas, not screenshots of a running database. The e-commerce project is presented as a design artefact, consistent with its README.
